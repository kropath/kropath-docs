# AWS ECS

Elastic Container Service (ECS) provides container orchestration, task management, and auto-scaling for containerized applications across EC2 and serverless Fargate launch types.

## Resources

*   [ECS Overview & Configuration](ecs.md) — Comprehensive guide to ECS governance, configuration, and resource types.

## Resource Types

*   **ECSConfig** — Governance configuration for ECS settings (launch types, platform versions, networking, resource sizing, naming).
*   **ECSCluster** — Manages ECS clusters with capacity providers and monitoring.
*   **ECSService** — Manages containerized services with deployment strategies and load balancing.
*   **ECSTaskDefinition** — Defines task specifications (images, roles, volumes, compute).
*   **ECSCapacityProvider** — Manages EC2 and Fargate capacity with auto-scaling.
