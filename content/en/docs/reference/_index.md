Exhaustive, field-by-field documentation for every kropath resource kind, organized by cloud
provider and then by service.

This section is a reference: use it to look up specific fields, defaults, and validation rules.
It is not meant to be read sequentially. If you are learning how to provision your first
resource, start with the [Tasks]({{< relref "/docs/tasks" >}}) section instead.

## Finding what you need

Resources are grouped by cloud provider and then by service. For example, AWS S3 resources are
under **AWS > S3**, and IAM resources are under **AWS > IAM**.

Within each service:
- The service landing page lists all resource kinds available for that service
- Each resource kind has its own detailed page with all fields, defaults, and constraints

Use the left navigation to browse, or the search function to find a specific resource or field.
