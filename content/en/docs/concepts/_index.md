This section explains the fundamental ideas behind kropath. Understand how governance flows
through namespace tiers, how configuration is inherited and composed, and how naming templates
give resources meaningful, consistent identifiers across your infrastructure.

Read this section first if you are new to kropath, or jump to specific concepts if you want
to understand a particular aspect in depth. If you are ready to start a task instead, see the
