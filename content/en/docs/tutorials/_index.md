Tutorials build on the [Tasks]({{< relref "/docs/tasks" >}}) section, chaining several goals
into a longer, guided learning path.

## When to use tutorials

- You are learning kropath for the first time and want a comprehensive walkthrough
- You want to build a complete end-to-end workflow, not just one isolated task
- You want to see how multiple resources and configurations work together

If you have a specific, focused goal in mind, the [Tasks]({{< relref "/docs/tasks" >}}) section
may be more efficient. Tutorials are designed for learning and exploration.

## Available tutorials

More tutorials are coming soon. Start with a [Task]({{< relref "/docs/tasks" >}}) if you have a
specific goal in mind.
